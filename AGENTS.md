# Contributor guide

Run `make test` and `make eval` before every commit; both replay recorded model responses and need no API key. Never commit a real bank statement, account number or name: every fixture under `evals/fixtures/` and `tests/fixtures/` is synthetic and is regenerated by `uv run python -m evals.make_fixtures`, so change the generator rather than editing a PDF by hand. Follow [SECURITY-RULES.md](SECURITY-RULES.md) for secrets, data and workflows, and [CONTRIBUTING.md](CONTRIBUTING.md) for the rest.
